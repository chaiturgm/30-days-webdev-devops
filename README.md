# 30 Days of Web Dev + DevOps

A 30-day challenge to learn web development and DevOps from scratch, with one push to this repo every day.

## Goal

By Day 30, I will have built a full-stack to-do app (HTML/CSS/JS, React, Node/Express, database), containerized it with Docker, set up CI/CD with GitHub Actions, and deployed it on a cloud VM with HTTPS.

## Commitment

- 1 to 2 hours every day
- Daily time slot: 10:00 AM to 12:00 PM
- One commit pushed every day
